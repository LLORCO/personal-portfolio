| Propuesta | Descripción |

| **Third-party integrations** | Apps, reviews (Junip, etc.), checkout extensions, APIs en storefront |
| **Shopify performance** | Optimización de carga, assets, lazy loading, Core Web Vitals |
| **Multi-brand / multi-store** | Consistencia visual y técnica entre tiendas o mercados |
