# Portfolio Layout Structure

## 1) Hero
- Strong value proposition headline.
- Positioning statement: frontend + design + technical depth.
- Supporting value card with 3 differentiators.
- Floating but clean top navigation with single CTA.

## 2) About
- Story and working mindset.
- Three concise principle cards: consistency, microinteractions, maintainable code.

## 3) Projects
- Three high-quality case-study style cards.
- Each card highlights:
  - Context and approach
  - Tech stack
  - Outcome or measurable impact

## 4) Skills
- Grouped by:
  - Frontend
  - Backend
  - Tools
- Balanced communication of specialization + end-to-end capability.

## 5) Community / Talks
- Dedicated section to leadership and communication.
- Cards for events, talks, and mentorship contributions.

## 6) Contact
- Clear conversion-oriented CTA.
- Role availability + freelance fit.
- Primary contact plus professional links.
